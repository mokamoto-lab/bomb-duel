# BOMB DUEL

PC・携帯で遊べる、爆弾対戦ゲームの公開版プロトタイプです。

## 遊び方

メニューから「PC / キーボード」「携帯 / タッチ」と、「2人で対戦」「1人 / ストーリー」を選べます。

- プレイヤー1：WASDで移動、Spaceで爆弾。
- プレイヤー2：矢印キーで移動、Enterで爆弾。
- 携帯：左の方向パッドで移動、右の丸いボタンで爆弾。
- Pで一時停止、Rで現在のステージをリセット。

爆弾は2秒後に十字に爆発します。相手に爆風を当てると勝ち、自分の爆風にも当たります。同時に当たると引き分けです。初期の爆風は上下左右それぞれ1マスで、火力アップを拾うと伸びます。アイテムはプレイ時間15秒ごとに1個出現します。

ステージの外周はプレイ時間60秒ごとに1層ずつ消滅します。10秒前から対象の行・列がオレンジ色に点滅し、残り時間と行・列番号を表示します（左上を行1・列1として、壁も含めた番号）。消滅するマスに残ると敗北、両者が残ると引き分けです。消滅した場所へは戻れず、その場所の爆弾とアイテムも消えます。CPUも点滅する外周から逃げます。5分で最後の中央列が消滅し、決着します。一時停止中は出現・消滅のタイマーも止まります。

2人対戦は1台の端末を共有します。別々の端末を接続するオンライン対戦には対応していません。

## ストーリー

10章・全100ステージのCPU対戦です。ステージ1〜3は練習向けで、CPUの動作と攻撃を弱くしています。後半ほど、判断速度・爆風予測・退路の確保・アイテム取得・攻撃の先読みが強くなります。

ステージごとに固定シードで配置を生成します。100ステージを手作業で制作したものではありません。章タイトルと短い案内を備えた、ステージ進行型のストーリープロトタイプです。

解放済みステージと操作設定は、そのブラウザのローカルストレージに保存します。他の端末・ブラウザ・URLには引き継がれません。

## 公開と更新

`index.html` と `.nojekyll` をGitHub Pagesで配信します。ビルドやAPIキーは不要です。`main` ブランチのルートを公開対象に設定しています。

更新するときは `index.html` を変更し、`main` へコミットしてプッシュしてください。GitHub Pagesが同じ公開URLへ自動反映します。

```sh
git add index.html
git commit -m "feat: update game"
git push origin main
```

`index.html` 単体をブラウザで開いて、ローカルで遊ぶこともできます。
